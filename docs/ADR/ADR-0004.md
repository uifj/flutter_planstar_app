# ADR-0004: 优惠券、兑换码与礼品卡为演示数据，无真实后端端点

- **状态**: PROPOSED
- **分类**: DEF
- **优先级**: P2
- **影响维度**: 生产功能 / 幻觉源
- **日期**: 2026-11-16
- **来源**: 全量接口审计
- **修复 commit**: —

## 背景（Context）

营销资产三个页面全部使用本地演示数据，且不区分数据源：

- **优惠券**：[coupon_providers.dart#L19-L25](../../lib/features/marketing/coupon_providers.dart#L19-L25) 的 `couponListProvider` 直接返回 `DemoCoupons.generate()`，注释也承认"目前只有演示数据"。
- **兑换码**：[coupon_providers.dart#L77-L127](../../lib/features/marketing/coupon_providers.dart#L77-L127) 用内存模拟兑换：任意 8 位以上兑换码即视为成功，不落库、不校验真伪。
- **礼品卡**：[gift_card_providers.dart#L7-L12](../../lib/features/marketing/giftcard/gift_card_providers.dart#L7-L12) 的 `giftCardListProvider` 直接返回 `DemoGiftCards.all`。
- **后端缺口**：`rg -n 'coupon|giftcard|giftCard|exchange' planstar_kratos_server/planstar/internal/service/service.go` 无命中；`ApiPaths` 中也没有对应常量。
- **对比**：星币钱包是真实接口（[wallet_providers.dart#L56-L71](../../lib/features/marketing/wallet_providers.dart#L56-L71) 区分 demo/remote，remote 走 `v1/moneyaccount`），但"我的"页把真实钱包与演示券数量并排展示（[coupon_providers.dart#L43-L46](../../lib/features/marketing/coupon_providers.dart#L43-L46) 的 `couponCountProvider`），真实用户会看到凭空出现的券资产。

用户可见影响：券数量、可用/已用/过期状态、礼品卡余额均为编造；兑换码"随便输就能成功"，属于会误导用户的假成功。

## 决策（Decision）

候选方案：

- **A. 后端补齐营销域端点**：`GET /v1/coupons`、`POST /v1/coupons/exchange`、`GET /v1/giftcards`、`POST /v1/giftcards`（绑定/兑换）。**需后端与运营协作**（券模板、发放规则、风控）。
- **B. 前端按 `DataSourcePolicy` 分支**：真实模式下券/礼卡列表返回空态并隐藏数量角标，兑换页提示"暂未开放"，不再返回假成功。
- **C. 保持现状但加"演示"水印**。

选定：**B 立即执行 + A 作为中期目标**。理由：假兑换成功属于高风险的"幻觉源"（用户会认为资产已到账），必须优先消除；真实资产体系涉及发放与核销，需后端与运营共同设计，不宜前端先行定义接口。

## 后果（Consequences）

- **正面**: 真实模式不再展示不存在的券/礼卡资产，也不再出现假兑换成功。
- **负面/风险**: 真实模式下营销入口为空，需产品确认是否隐藏入口；A 未落地前无法做任何真实发券活动。
- **中性**: `Coupon` / `GiftCard` 领域模型与页面结构可复用，A 落地时只替换数据源。

## 验证（Verification）

```bash
# 后端当前无营销端点（A 落地后应命中）
rg -n 'coupon|giftcard' planstar_kratos_server/planstar/internal/service/service.go

# 演示数据引用面（B 落地后真实模式不应再走到这里）
rg -n 'DemoCoupons|DemoGiftCards' flutter_planstar_app/lib

# 回归（营销页在 pages_smoke_test 中覆盖）
flutter test test/features/pages_smoke_test.dart
```

- 真实模式手测：`/coupons`、`/coupons/exchange`、`/giftcards` 不再展示编造资产；输入任意兑换码不会提示"兑换成功"。
- "我的"页在真实模式下不展示无法解释的券数量角标。
