# ADR-0003: 城市列表为本地常量，后端无 `/v1/cities`，真实模式下城市切换不生效

- **状态**: PROPOSED
- **分类**: DEF
- **优先级**: P2
- **影响维度**: 生产功能 / 幻觉源
- **日期**: 2026-11-16
- **来源**: 全量接口审计
- **修复 commit**: —

## 背景（Context）

- 城市列表完全来自前端常量：[demo_catalog.dart#L21](../../lib/features/catalog/data/demo_catalog.dart#L21) 的 `demoCities`。
- 页面直接消费该常量：[city_list_page.dart#L62-L73](../../lib/features/home/city_list_page.dart#L62-L73) 的"热门城市 / 全部城市"两个分组都是 `demoCities.take(8)` 与 `demoCities`。
- 后端没有任何城市端点：`rg -n 'cities' planstar_kratos_server/planstar/internal/service/service.go` 无命中；`ApiPaths` 中也无 `cities` 常量。
- 真实模式下城市选择对数据没有影响：[catalog_providers.dart#L274-L287](../../lib/features/catalog/application/catalog_providers.dart#L274-L287) 注明"企划数据没有城市字段（全国发行），真实模式直接返回全量"，只有 demo 模式才按 `selectedCityProvider` 过滤。

用户可见影响：真实模式下切换城市后，列表内容不变（只改了 AppBar 的城市名），用户会误以为"该城市没有数据"或"筛选失效"；`demoCities` 中部分城市在真实数据里从未存在。

## 决策（Decision）

候选方案：

- **A. 后端新增 `GET /v1/cities`（含热门标记与是否已开通）**，前端改为 `FutureProvider`，未开通城市置灰并提示。**需后端/运营协作**（城市开通状态属于运营配置）。
- **B. 前端按 `DataSourcePolicy` 分支**：真实模式隐藏城市入口（顶部直接展示"全国"），demo 模式保留现有列表。
- **C. 保持现状但在城市页标注"演示数据"**。

选定：**B 立即执行 + A 作为中期目标**。理由：项目在真实模式下本就是"全国发行"，隐藏一个不生效的筛选器比保留更符合事实；A 的价值在于后续线下场地/同城活动，届时再按运营配置接入。

## 后果（Consequences）

- **正面**: 消除"切换城市无效果"的误导；真实模式 UI 与数据能力一致。
- **负面/风险**: 真实模式失去城市入口，需产品确认入口位置（或改为"全国"只读文本）；`/cities` 路由可保留但入口隐藏。
- **中性**: `selectedCityProvider` 与 `cityShowsProvider` 的城市过滤分支保留给 demo 模式，不影响现有测试。

## 验证（Verification）

```bash
# 后端当前无城市端点（A 落地后应命中 1 条）
rg -n 'cities' planstar_kratos_server/planstar/internal/service/service.go

# 前端常量引用面
rg -n 'demoCities' flutter_planstar_app/lib
```

- 真实模式手测：首页顶部不再展示可点击的城市切换项（或展示只读"全国"），进入 `/shows` 后数据不再随城市变化而"看起来更少"。
- demo 模式手测：城市页仍展示 `demoCities` 并可切换过滤。
