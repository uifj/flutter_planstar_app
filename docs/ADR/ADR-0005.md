# ADR-0005: 意见反馈与编辑资料保存无后端接口，前端提示成功但不落库

- **状态**: PROPOSED
- **分类**: DEF
- **优先级**: P2
- **影响维度**: 生产功能 / 幻觉源
- **日期**: 2026-11-16
- **来源**: 全量接口审计
- **修复 commit**: —

## 背景（Context）

两个表单页面在提交时只弹提示并返回，不发起任何请求：

- **意见反馈**：[feedback_page.dart#L224-L230](../../lib/features/user/feedback_page.dart#L224-L230)

  ```dart
  void _submit() {
    // 不实际提交：反馈接口后端未实现。
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text(context.l10n.feedbackPage_230)),
    );
    context.pop();
  }
  ```

- **编辑资料**：[edit_profile_page.dart#L241-L247](../../lib/features/user/edit_profile_page.dart#L241-L247)

  ```dart
  void _save() {
    // 不实际提交：修改资料接口后端未实现。
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text(context.l10n.editProfilePage_229)),
    );
    context.pop();
  }
  ```

- **后端缺口**：[service.go#L105-L111](../../../planstar_kratos_server/planstar/internal/service/service.go#L105-L111) 只有 `GET /v1/user`（及尾斜杠别名）与地址相关路由；没有 `POST /v1/user/feedback`，也没有 `POST/PUT /v1/user/profile`（或等价更新接口）。
- `ApiPaths` 中也无 feedback / updateProfile 常量。

用户可见影响：编辑昵称/头像/简介后提示"保存成功"并返回，但再次进入页面仍是旧数据；反馈提交后提示"已提交"，实际无人收到。两者都是典型的"假成功"，会让用户对数据一致性失去信任。

## 决策（Decision）

候选方案：

- **A. 后端补齐端点**：`POST /v1/user/feedback`（提交反馈）、`PUT /v1/user/profile`（更新资料，含字段级校验），前端接真实接口并处理失败态。**需后端协作**（字段白名单、敏感词/审核、头像上传）。
- **B. 前端短期止血**：按钮改为"暂未开放"并禁用；或保留表单但提交时明确提示"当前版本暂不支持提交"，不返回成功页。
- **C. 本地暂存草稿**：资料修改落 `AppStore.preferences`，下次进入回填。**不建议**：造成"已修改"的错觉，且与服务端用户资料冲突。

选定：**B 立即执行 + A 作为中期目标**，明确排除 C。理由：假成功比不可用更伤信任；本地草稿会制造更隐蔽的数据不一致（服务端仍是旧值，且多端不同步）。

## 后果（Consequences）

- **正面**: 消除"提示成功但数据未变"的误导；用户对不可用功能有明确预期。
- **负面/风险**: 真实模式下两个入口在 A 完成前不可用，需产品确认文案；A 涉及审核与上传，排期较长。
- **中性**: 表单 UI 与校验逻辑可保留，A 落地时只需接上提交函数与错误提示。

## 验证（Verification）

```bash
# 后端当前无对应端点（A 落地后应命中 2 条）
rg -n 'feedback|profile' planstar_kratos_server/planstar/internal/service/service.go
```

- 真实模式手测：`/feedback` 提交后不再出现"提交成功"类文案；`/me/edit-profile` 保存后不再提示成功，且按钮状态与文案明确表达"暂未开放"。
- A 落地后：抓包应出现 `POST /v1/user/feedback status=200`、`PUT /v1/user/profile status=200`；重新进入页面数据已更新；失败时展示可重试的错误提示。
