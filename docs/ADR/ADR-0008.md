# ADR-0008: 六个页面仅注册路由但应用内无入口，实际不可达

- **状态**: PROPOSED
- **分类**: DEF
- **优先级**: P2
- **影响维度**: 认知障碍 / 上下文膨胀 / 生产功能
- **日期**: 2026-11-16
- **来源**: 全量页面可达性审计（router 路由表 × 前端导航调用面 × 深链映射表）
- **修复 commit**: —

## 背景（Context）

审计方法：先取 [router.dart#L124-L489](../../lib/app/router.dart#L124-L489) 中全部 `GoRoute` 与页面 import，再对每个页面文件反向搜索三类入口——`context.push/go`、`PlanstarLinks.hostToPath`（[planstar_links.dart#L11-L40](../../lib/app/planstar_links.dart#L11-L40)）、`Navigator` 命令式跳转（全库 `MaterialPageRoute|PageBuilder|Navigator.of(context).push` 无命中，导航已统一走 go_router）。

结果：所有页面文件都已在路由表注册，但下列 6 个页面在应用内**没有任何入口**，只能手动输入 location 到达：

| 页面 | 路由 | 入口核对结果 |
|---|---|---|
| `ProxyBuyPage` | `/proxy-buy` | 除路由定义 [router.dart#L468-L474](../../lib/app/router.dart#L468-L474) 与登录门禁清单 [#L72](../../lib/app/router.dart#L72) 外，全库无 `'/proxy-buy'` 跳转；路由注释自述"遗留票务能力……待下线" |
| `GroupBuyPage` | `/group-buy` | 仅路由定义 [router.dart#L475-L480](../../lib/app/router.dart#L475-L480)；全库无 `context.push('/group-buy')` |
| `GroupBuyDetailPage` | `/group-buy/:id` | 唯一入口是 [group_buy_page.dart#L47](../../lib/features/group_buy/ui/group_buy_page.dart#L47) 的 `context.push('/group-buy/${...}')`；但列表页本身不可达，故详情页同样不可达 |
| `CouponPage` | `/coupons` | [user_page.dart#L685](../../lib/features/user/user_page.dart#L685) 明确注释"优惠券入口已按产品要求暂时隐藏（路由 `/coupons` 保留，恢复时加回）"；[user_page.dart#L692-L712](../../lib/features/user/user_page.dart#L692-L712) 的快捷区只有商城 / 钱包 / 礼品卡 |
| `ExchangeCouponPage` | `/coupons/exchange` | 唯一入口是 [coupon_page.dart#L37](../../lib/features/marketing/coupon_page.dart#L37)；上游 `CouponPage` 不可达，故兑换页也不可达 |
| `VenuePage` | `/venue/:name` | 仅路由定义 [router.dart#L229-L236](../../lib/app/router.dart#L229-L236)；全库无 `'/venue/'` 跳转 |

`VenuePage` 还有一条完整的死代码依赖链：其唯一设计入口 `HomeVenuesFloor`（[home_venues_floor.dart#L17-L37](../../lib/features/home/widgets/home_venues_floor.dart#L17-L37)）在 [home_page.dart](../../lib/features/home/home_page.dart) 中没有被引用（`HomeVenuesFloor` 全库仅命中定义处），因此 [popularVenuesProvider#L431](../../lib/features/catalog/application/catalog_providers.dart#L431) → [venueByNameProvider#L462](../../lib/features/catalog/application/catalog_providers.dart#L462) → [venue_page.dart#L41](../../lib/features/goods/venue_page.dart#L41) 这条链路在真实导航中从未被执行。

可达性自检命令（当前结果均为"仅路由/定义处命中"）：

```bash
rg -n "push\('/proxy-buy|push\('/group-buy'|push\('/coupons|push\('/venue/" flutter_planstar_app/lib
rg -n '/venue/|/proxy-buy|/group-buy|/coupons' flutter_planstar_app/lib/app/planstar_links.dart
# 均无输出 → 无普通入口、无深链入口
```

补充事实：`/cities` 在真实模式下同样不可达（[home_page.dart#L207-L230](../../lib/features/home/home_page.dart#L207-L230) 的 `onTapCity` 仅在 `policy.isDemo` 时非空，[category_home_page.dart#L113](../../lib/features/catalog/ui/category_home_page.dart#L113) 同理），但 demo 模式仍可用，已由 ADR-0003 单独记录，此处不重复计入。

`VenuePage` 仍被 [pages_smoke_test.dart#L233](../../test/features/pages_smoke_test.dart#L233) 直接构造，说明它"可渲染"，但测试构造不等于应用内可达。

## 决策（Decision）

候选方案：

- **A. 恢复入口**：代抢/组队恢复入口依赖 ADR-0001 的后端端点；优惠券恢复入口依赖 ADR-0004 的真实券数据；场地页恢复入口只需重新挂 `HomeVenuesFloor`。
- **B. 删除页面与路由**：适用于已确定下线的能力，连同死代码（`HomeVenuesFloor`、`popularVenuesProvider`、`venueByNameProvider`）一起清理。
- **C. 保留并标注"待接线"**，同时加路由守卫（未开放路由重定向首页或提示）。

选定：**按能力分组处置，并新增可达性契约测试防回归**。

1. `/proxy-buy`、`/group-buy`、`/group-buy/:id`：与 ADR-0001 绑定。若后端不补端点，**选 B 删除路由与页面**，不保留"能进但必然 404"的死路由。
2. `/coupons`、`/coupons/exchange`：与 ADR-0004 绑定。短期维持隐藏（现状），若产品确认不做营销域，则**选 B 一并删除**。
3. `/venue/:name`：`VenuePage` 本身已实现且有 smoke test，**选 A 恢复入口**（重新引用 `HomeVenuesFloor`，或在场地卡片/详情页加入口）；若产品确认不做场地维度，则改为 B 并删除整条链路。
4. 新增路由可达性测试（TST 类）：枚举 `router.dart` 中所有非参数化 location，断言每个 location 在 `lib/` 内至少存在一个 `push/go` 或深链映射引用；白名单仅允许 `/splash`（初始页）等确实无入口的路由。

## 后果（Consequences）

- **正面**: 消除"路由存在即功能存在"的误判；减少无效维护面与编译体积；新同事/后续审计不再把这些页面当作可用功能。
- **负面/风险**: 删除路由属于行为变更，需确认没有外部深链依赖（当前 `PlanstarLinks` 未映射这些 host）；恢复场地入口需要确认首页楼层布局空间。
- **中性**: 页面代码本身可作为后续重做的参考；`VenuePage` 的 smoke test 保留或随页面删除同步调整。

## 验证（Verification）

```bash
# 1. 入口断言：修复后每个保留路由都应命中至少一条 push/go
rg -n "push\('/venue/|push\('/coupons|push\('/group-buy|push\('/proxy-buy" flutter_planstar_app/lib

# 2. 死代码断言：删除方案下应无输出
rg -n 'HomeVenuesFloor|popularVenuesProvider|venueByNameProvider' flutter_planstar_app/lib

# 3. 路由清单与入口清单的一致性测试
flutter test test/app/router_reachability_test.dart

# 4. 既有回归
flutter test test/features/pages_smoke_test.dart
```

- 真实模式手测：`/proxy-buy`、`/group-buy`、`/coupons`、`/venue/梅赛德斯-奔驰文化中心` 要么从 UI 可达且数据正常，要么路由已删除（返回首页/未匹配兜底），不再出现"只能手动输入 location 才能打开"的中间状态。
