# ADR-0006: 座位图与锁座均为本地实现，服务端无座位库存，订单只提交数量

- **状态**: PROPOSED
- **分类**: DEF
- **优先级**: P1
- **影响维度**: 生产功能 / 幻觉源
- **日期**: 2026-11-16
- **来源**: 全量接口审计
- **修复 commit**: —

## 背景（Context）

线下回报场次的选座能力完全在前端模拟：

- **座位图本地生成**：[seat_selection_providers.dart#L19-L31](../../lib/features/goods/seatmap/seat_selection_providers.dart#L19-L31) 的 `seatMapDataProvider` 直接调用 `DemoSeatMap.generate(...)`，仅当真实模式且详情可用时取后端权威单价 `show.priceFrom` 作为座位价格；注释明确"服务端未提供座位图端点"。
- **锁座是进程内内存锁**：[seat_selection_providers.dart#L33-L40](../../lib/features/goods/seatmap/seat_selection_providers.dart#L33-L40) 的 `seatLockServiceProvider` 注释写明"服务端座位库存未接入——锁只在当前 App 进程内有效，其他用户/其他设备看不到，也不会在服务端占座"；选座与超时释放见 [#L146-L191](../../lib/features/goods/seatmap/seat_selection_providers.dart#L146-L191)、[#L205-L230](../../lib/features/goods/seatmap/seat_selection_providers.dart#L205-L230)。
- **订单只带数量，不带座位**：[order_confirm_controller.dart#L161](../../lib/features/order/application/order_confirm_controller.dart#L161) 只订阅 `seatSelectionProvider(showId).select((state) => state.count)`；座位 ID 集合从未进入下单请求。
- **后端缺口**：`rg -n 'seat|Seat' planstar_kratos_server/planstar/internal` 无命中；[service.go#L96-L103](../../../planstar_kratos_server/planstar/internal/service/service.go#L96-L103) 的订单/支付链路只接受回报档位与数量，没有座位参数。

用户可见影响：两名用户可以选中同一个座位并各自完成下单；应用杀进程或换设备后"已锁"座位立即释放；订单成功并不代表该座位已保留。用户会认为"选中的座位已锁定"，属于高风险的错误预期。

## 决策（Decision）

候选方案：

- **A. 后端补齐座位域**：`GET /v1/projects/{id}/shows/{sessionId}/seat-map`（或等价）、`POST /v1/seat-locks`（带 TTL 与幂等键）、`DELETE /v1/seat-locks/{token}`，并在下单请求中携带 `seatIds`、服务端做并发校验。**需后端协作**（库存表、锁超时、并发控制）。
- **B. 真实模式下线选座入口**：线下回报场次只保留"按数量购票"（与现有下单口径一致），demo 模式保留选座演示。
- **C. 保留选座但把"占座成功"文案改为"仅本地预览，提交后以出票结果为准"**。

选定：**B 立即执行 + A 作为中期目标**，C 仅作为 A/B 之间的过渡文案。理由：当前订单链路本就不接受座位，继续展示"选座并锁座"会制造无法兑现的承诺；按数量购票与后端现状一致，改动最小且不产生错误预期。

## 后果（Consequences）

- **正面**: 消除"已占座"的错误预期，避免并发重复售座引发的售后争议。
- **负面/风险**: 真实模式失去选座体验，需产品/运营确认线下场次的售卖方式；A 完成前无法支持对号入座。
- **中性**: `SeatMapData` / `SeatContinuityPolicy` / WebView 桥接等实现保留给 demo 模式与 A 落地复用。

## 验证（Verification）

```bash
# 后端当前无座位端点（A 落地后应命中）
rg -n 'seat|Seat' planstar_kratos_server/planstar/internal

# 前端锁座与座位图来源
rg -n 'DemoSeatMap|seatLockServiceProvider' flutter_planstar_app/lib

# 回归
flutter test test/features/goods/seatmap
```

- B 落地后：真实模式线下场次无法进入 `/seat-selection`（入口隐藏或提示"暂不支持选座"）；下单请求体不含 `seatIds` 仍可成功。
- A 落地后：并发手测两个账号选同一座位，第二个请求应返回冲突；杀进程后重新进入，已被服务端锁定的座位仍不可选；订单详情可回显座位号。
